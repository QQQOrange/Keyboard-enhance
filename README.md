# CapsLock+ 图形版（Windows 11 x64）

把 [wo52616111/capslock-plus](https://github.com/wo52616111/capslock-plus) 那套 AutoHotkey 脚本，
重写成 **原生 Windows 11 桌面程序**：CapsLock 依然是功能键，但所有设置都能在图形界面里点点点完成，
不用再手改 `CapsLock+settings.ini`。

- 按住 **CapsLock** 就是功能键：字母键移动/选择光标，数字键切窗口，**Caps+Q** 打开搜索面板
- 短按 Caps 还是切换大小写，日常打字完全不受影响
- 全部按键映射、Qbar 条目、窗口绑定、外观，都在界面里改，**改完立刻生效**
- 旧的 `CapsLock+settings.ini` 可以一键导入
- 内置自动更新：勾选后每次启动自动检查，发现新版先询问再下载，下载完自动替换重启

**本版本：v1.0.0**　仓库地址：<https://github.com/QQQOrange/capslock-plus-QQQOrange->

## 一、直接使用

1. 双击 `CapsLockPlus.exe`（首次运行会请求管理员权限，用于操作以管理员身份运行的程序）
2. 首次启动会出现三步引导：选按键方案 → 是否开机自启 → 试一下
3. 之后程序常驻托盘，右键托盘图标可随时打开设置

**运行要求**：Windows 10 1809 及以上 / Windows 11，x64，已安装 **.NET 10 桌面运行时**
（`Microsoft.WindowsDesktop.App`）。程序本身是单文件，约 1.2 MB。

运行时**不在仓库里**，请到官网按版本下载安装：

> 下载页面：<https://dotnet.microsoft.com/download/dotnet/10.0>
> 选择 **.NET 10.0 → Desktop Runtime → Windows x64**（就是列表里的
> “.NET Desktop Runtime 10.x.x · Windows · x64” 那一项），
> 安装后再运行本程序即可。

> 没有管理员权限也能跑，只是无法操作提权窗口；启动时如果拒绝了 UAC，程序会自动降级为普通权限继续运行。

## 三、Qbar：一个输入框搞定大部分事

按 `Caps+Q`（或在设置里打开"双击 Caps 打开 Qbar"）。

### 十、许可

输入 `bd` 再按 **空格**，`bd` 就从文字变成一枚标签：

- 有图标 → 直接显示图标（例如百度）
- 没有图标 → 显示「名字 + 品牌色首字」，例如 `计算器`

变成标签后，输入框里只剩**要搜索的内容**，输入完回车即可：

```
[🔵 百度]  天气 预报        →  Enter  →  用百度搜索"天气 预报"
```

- `Backspace`（输入框为空时）把标签还原成文字，方便改关键字
- 点标签右边的 `×` 也可以移除
- `Tab` 键同样能把关键字变成标签

### 输入规则

| 输入 | 结果 |
| --- | --- |
| `bd` + `空格` + `天气` | 变成「百度」标签，搜索"天气" |
| `calc` + `空格` | 变成「计算器」标签，回车启动 |
| `gh` + `空格` | 变成「GitHub」标签，回车打开 |
| `=1+2*3` | 立刻算出 `7`，回车复制到剪贴板 |
| `/settings` | 打开设置 |
| `C:\path\to\file` | 打开该文件 / 文件夹 |
| 任意文字 | 回车用默认搜索引擎搜索 |

- `↑` `↓` 选择，`Enter` 执行，`Tab` 补全，`Esc` 关闭
- 程序、网址、搜索指令、剪贴板历史、已打开的窗口都会参与匹配

### 图标从哪来

按优先级自动取：

1. 你在「Qbar 面板」页里给该条目指定的**图标**（png / ico / 任意 exe，或点「选择…」）
2. 程序条目自动使用**该 exe 的图标**（免配置）
3. 都没有 → 显示「名字首字 + 品牌色」的圆角标签

内置的 9 个搜索指令（百度 / Google / Bing / 淘宝 / 维基 / GitHub / MDN / 知乎 / 翻译）都自带矢量图标，离线可用。

## 五、更新

「关于」页有两个入口：

- **自动更新**（开关）：勾选后，每次启动会在后台静默检查（同一台机器一天最多一次）。
  发现新版本会弹出提示，问你要不要下载；点「下载并安装」后**就在当前窗口下载**，
  完成后自动替换旧程序并重启，无需手动操作。
  如果某个版本你不想装，点「跳过此版本」，之后再出新版仍会提醒。
- **检查更新**（按钮）：立刻检查一次，有新版会显示版本号、体积和更新说明。

更新流程为：下载到临时目录 → 校验 SHA-256（发布方提供时）→ 旧程序改名 →
新程序就位 → 启动新版本。旧文件会在下次启动时自动清理。

## 六、从旧版迁移

「设置 → 从旧版 CapsLock+ 导入设置」，选择旧的 `CapsLock+settings.ini`：

- `[Keys]` 里的 `keyFunc_xxx(参数)` 会映射成新版的"动作 + 参数"
- `[QSearch]` / `[QRun]` / `[QWeb]` / `[TabHotString]` 全部导入
- `autostart`、`mouseSpeed`、`allowClipboard` 一并迁移
- 少数无法自动映射的（例如自定义 `keyFunc_doubleChar` 的包裹字符）会在导入结果里列出，需要手动确认

## 七、和上游的差异

**保留**：Caps 组合键的全部语义、两套按键方案、Qbar 的搜索/启动/计算、独立剪贴板、窗口绑定、Tab 计算与热字串。

**改进**：

| 方面 | 上游（AutoHotkey） | 本版本 |
| --- | --- | --- |
| 配置方式 | 手改 UTF-16 的 ini 文件 | 图形界面，JSON 存储，改完即时生效 |
| 计算能力 | 依赖 IE 引擎跑 JS | 自带表达式解析器，Win11 无 IE 也能算 |
| 钩子稳定性 | 长时间运行后钩子可能被系统摘掉 | 每秒巡检，异常自动重装 |
| 按键延迟 | 钩子里直接跑功能 | 钩子只做判断，功能入队执行，不会被系统摘钩 |
| 剪贴板监听 | 定时器轮询 | `WM_CLIPBOARDUPDATE` 消息驱动，空闲零 CPU |
| 翻译 | 有道（需付费 key） | 内置免密钥引擎兜底，也可填有道 key |
| 搜索关键字 | 纯文本，要记住缩写 | **变成带图标的标签**，一眼看出用的哪个引擎 |
| 启动速度 | — | 首屏约 0.6 秒，单文件 1 MB |

## 八、常见问题

**按住 Caps 没反应？**
检查托盘图标是否存在、设置页"运行状态"是否为"已启用"。若显示"键盘钩子未生效"，点一下"暂停"再"恢复"即可重装。

**某些程序里组合键不生效？**
以管理员身份运行的程序（任务管理器、部分游戏）需要本程序也提权。启动时同意 UAC 即可。

**Caps 不能切换大小写了？**
短按 Caps 默认就是切换大小写；如果改成了"什么都不做"，到「设置 → 按键行为」改回来。

**想彻底退出？**
右键托盘图标 → 退出。关闭窗口只是最小化到托盘。

**设置文件在哪？**
`%LocalAppData%\CapsLockPlus\settings.json`（设置页有"打开设置文件"按钮），日志在同目录 `logs\app.log`。

## 九、开发

```powershell
# 构建
dotnet build src\CapsLockPlus\CapsLockPlus.csproj

# 发布单文件（需要 .NET 10 SDK）
dotnet publish src\CapsLockPlus\CapsLockPlus.csproj -c Release -r win-x64 --self-contained false -o dist

# 自检（88 项，覆盖按键模型、表达式、Qbar、设置迁移、钩子、组合键状态机）
dist\CapsLockPlus.exe --selftest

# 离屏渲染所有界面（文档/回归用，不受桌面遮挡影响）
dist\CapsLockPlus.exe --render out\shots
```

**代码结构**

```
src/CapsLockPlus/
├─ Core/                    与界面无关的核心逻辑（可在无界面下自检）
│  ├─ Input/                键盘钩子、Caps 组合键状态机、按键名映射、输入注入
│  ├─ Actions/              动作目录、动作上下文、剪贴板、窗口绑定
│  ├─ Windows/              窗口枚举/激活/贴边/置顶
│  ├─ Text/                 选区读写、表达式求值
│  ├─ Qbar/                 Qbar 检索与执行
│  ├─ Settings/             JSON 设置、旧版 ini 迁移、开机自启
│  └─ Translate/            翻译服务
├─ UI/                      WPF 界面
│  ├─ Windows/              主窗口、Qbar 浮层、计算器、翻译、引导、Toast
│  ├─ Views/                8 个页面
│  ├─ Theme/                主题、控件样式、Win11 窗口外观
│  └─ AppHost.cs            装配中心：引擎 + 托盘 + 窗口
├─ Theme/                   浅色/深色调色板与控件模板
└─ SelfTest.cs              自检
```

**设计要点**

- 钩子回调里**只做判断**，功能全部投递到 `ActionQueue` 的工作线程执行，避免超过系统 300ms 超时被摘钩
- 注入的按键带 `dwExtraInfo` 标记，钩子据此忽略自己发出的按键，不会自我触发
- 页面按需创建（`ContentControl` + 字典缓存），启动时只构建当前页
- 刻意不使用 `DropShadowEffect`：WPF 的阴影会把内容渲染到中间位图，既占内存又让文字发虚
- 主题、页面、动作目录全部数据驱动，新增一个动作只需在 `ActionCatalog` 里加一行
